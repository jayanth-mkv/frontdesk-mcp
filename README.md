# FrontDesk for Alexa+

> Focus on your work. FrontDesk fields every delivery call, doorbell and booking back-and-forth using your house rules, and only interrupts you when it matters.

A self-hosted **MCP server** (spec 2025-11-25, Streamable HTTP) for Alexa+, plus a web simulator. Built for the [Amazon Build, Ship, Shape hackathon](https://amazonappdev2026.devpost.com/).

🚧 Work in progress. See [`docs/STRATEGY.md`](docs/STRATEGY.md) and [`docs/ROADMAP.md`](docs/ROADMAP.md).
